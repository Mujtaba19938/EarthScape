Architecture

Public datasets are downloaded and stored in HDFS. Python jobs run on YARN through Hadoop Streaming, and their results are loaded into MongoDB. A FastAPI backend applies login and roles, and serves both this dashboard and the data.

NOAA, NASA, OpenAQ → HDFS → MapReduce on YARN → MongoDB → FastAPI → Dashboard

Live data and machine learning are later phases, and aren't part of this system yet.
