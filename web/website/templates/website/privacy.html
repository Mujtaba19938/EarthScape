This Policy Explains What EarthScape Stores And How It Is Protected.

This website and its dashboard are part of the EarthScape Climate Agency project. Most of what they show is public climate data, which contains no personal information.

‍

You can read the public website without an account. Signing in is only needed for the dashboard, which is for administrators and analysts.

‍

‍

What we store

To run the dashboard, EarthScape keeps a small amount of information about each person who has an account.

‍

  • Your name, role and email address
  • A secure hash of your password, never the password itself
  • The text of any support tickets you raise

‍

‍

How it is protected

Passwords are hashed with bcrypt. Email addresses and ticket text are encrypted in the database, and all traffic uses HTTPS. A sign-in lasts 8 hours and ends when you sign out.

‍

Only administrators can manage accounts, and the server checks each person’s role on every request. Backups are kept for recovery, and the latest seven are retained.

‍

‍

Climate data

Climate data comes from public sources such as NOAA, NASA, OpenAQ and Open-Meteo. It isn’t personal, so it isn’t encrypted.

‍

‍

Questions

This project follows common security practice, but it hasn’t been independently audited or certified. If you have a question about your data, please raise a ticket on the Feedback & Support page.
