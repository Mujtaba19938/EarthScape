About Service

About the big data processing service

Big Data Processing is the base of the platform. Files are loaded into HDFS, processed by MapReduce on YARN, and the results are copied to MongoDB.

01

Store in HDFS

Raw files are organised in folders by source and year, including 2.5 GB of NOAA station records for 2020 and 2023.

02

Process with MapReduce

Five Hadoop Streaming jobs written in Python work out data quality, regional patterns, unusual readings, satellite zones and air quality.

03

Handle Bad Data

Malformed rows, missing values and failed quality flags are skipped and counted, so one bad row never stops a job.
