About Service

About the live monitoring service

Live Monitoring keeps the platform current. A background collector fetches readings from Open-Meteo and makes them available on the Sensor Monitor page.

01

Collect the Readings

Every 15 minutes the collector reads the latest values for cities including Karachi, Tokyo, Lagos, London and Sao Paulo.

02

Check the Rules

After each collection, the new values are compared with the alert rules, so a problem shows up quickly.

03

Save for Later

Every hour, new readings are written to HDFS as a CSV file, joining the live data to the historical records.

{# Honest numbers you can check #}
How We Work

Honest numbers you can check

If HDFS is down, readings wait in MongoDB and are saved on the next attempt, so a stopped cluster doesn’t lose them.

This is scheduled polling rather than true streaming. It suits a single computer, and a tool like Kafka could replace the collector later.
