Different data calls for a different check

EarthScape looks for unusual readings in two ways. Station records get a statistical check in MapReduce, and air quality data gets a machine learning model.

Both only point to values worth checking. A flagged reading isn’t automatically an error or an event.

The Station Check

The station_anomalies job compares each reading with the mean for that station and month. Anything more than 3 standard deviations away is flagged, which comes to 48,715 readings.

A few limits apply to this check:

  • The baseline covers only 2020 and 2023
  • Station-months with too few readings are left out
  • The dashboard labels the baseline as short
  • Results are saved to MongoDB
  • The newest flags appear on the Executive Dashboard

Why It Matters

Nobody can read millions of rows by hand. Flagging the outliers gives people a short list to investigate.

‍

The Air Quality Model

An Isolation Forest model reads OpenAQ data with 30-day z-scores. Across 6,872 sensor-days from 24 sensors, it flagged 69, with 0.59% false flags in testing.

Nobody has labelled which days were truly abnormal, so we test it by adding artificial spikes.

How Well It Works

The model reliably finds large spikes and misses small ones. Artificial spikes only estimate real performance, and the dashboard shows these figures.

  • Spikes 3 times normal size: 1% found
  • Spikes 6 times normal size: 35% found
  • Spikes 10 times normal size: 100% found
  • Retraining updates these figures
