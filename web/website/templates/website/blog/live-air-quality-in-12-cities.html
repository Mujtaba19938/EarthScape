Twelve cities, with new readings every 15 minutes

Historical records show the long view, but people also need to know what’s happening now. EarthScape collects live air quality and weather readings for 12 cities from Open-Meteo.

The cities are Karachi, Delhi, Beijing, Tokyo, Jakarta, Sydney, Cairo, Lagos, Nairobi, London, New York and Sao Paulo.

How Collection Works

A background collector runs separately from the website. Every 15 minutes it fetches the latest values, stores them in MongoDB and checks them against the alert rules.

Each collection does four things, and an hourly batch adds a fifth:

  • Fetches the latest readings
  • Stores them for the dashboard
  • Checks them against alert rules
  • Updates the Sensor Monitor page
  • Saves an hourly CSV file to HDFS

Why It Matters

A value that crosses a limit is only useful if someone hears about it. Checking after each collection means an alert appears within about 15 minutes.

Polling, Not Streaming

This is scheduled polling rather than a streaming system. It suits one computer, and a tool such as Kafka could replace the collector later.

If HDFS isn’t running, readings wait in MongoDB and are saved on a later attempt.

Where to See It

Live readings appear on the Sensor Monitor page, and any alerts appear on Alert Management and as notifications.

  • Sensor Monitor: the latest values by city
  • Alert Management: rules and open alerts
  • Notifications: inside the dashboard
  • Reports & Export: the data as a file
