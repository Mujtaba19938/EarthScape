Architecture

Public datasets are downloaded and stored in HDFS. Python jobs run on YARN through Hadoop Streaming, and their results are loaded into MongoDB. A Django web application applies sign-in and roles, and renders both the website and this dashboard from MongoDB. Models train in Python on the results in MongoDB, and every run's scores are saved.

Browser → Apache (HTTPS, load balancing) → Two Django instances → MongoDB

NOAA, NASA, OpenAQ → HDFS → MapReduce on YARN → MongoDB → Django → Dashboard

MongoDB → scikit-learn, statsmodels → MongoDB (scores and forecasts)

Open-Meteo → Collector command → MongoDB → Alert rules → Email and notifications

Collector command → Hourly CSV batches → HDFS

Live data is collected on a timer, not through a streaming system such as Kafka. Each new value is available within one collection cycle.
